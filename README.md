# 🪨 Stone, Paper & Scissors Game

A fun and interactive **Stone, Paper & Scissors** game built using **HTML, CSS, and JavaScript**. Challenge the computer in a classic game with a clean, responsive interface and real-time score tracking. The game uses JavaScript to generate random computer moves, determine the winner, update scores dynamically, and display the result after every round.

## ✨ Features

* 🎮 Play against the computer
* 🧠 Random computer move generation
* ⚡ Instant win/lose/draw result
* 📊 Live score tracking
* 🎨 Clean and responsive user interface
* 🚀 Built with pure HTML, CSS, and JavaScript (no external libraries)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
